# uu 远控增强

UU 远程 iOS 客户端增强插件，支持 iOS 15.0 及以上。按需启用常用组合快捷键、圆盘鼠标滚轮、快捷切屏和缩放位置记忆。

当前版本：**1.0.2**。支持 UU 4.42.0（193）和 4.43.0（195）。

## 功能

- **电脑键盘常用组合键**：在组合键模式下，将下方原符号按键替换为 6 个常用快捷组合键：`Shift+Enter`、全选（`⌘A` / `Ctrl+A`）、撤销（`⌘Z` / `Ctrl+Z`）、剪切（`⌘X` / `Ctrl+X`）、复制（`⌘C` / `Ctrl+C`）、粘贴（`⌘V` / `Ctrl+V`）。自动识别被控电脑系统使用 Mac ⌘ 或 Windows Ctrl。
- **圆环虚拟滚轮**：将原生虚拟鼠标中间滚轮改为双层圆圈转盘效果，逆时针转圈向上滚动，顺时针转圈向下滚动，并根据旋转角速度自适应映射滚动速度。
- **多显示器视角记忆与定位修复**：记住各显示器的缩放比例与平移定位。在原生菜单「操作→显示→多显示屏管理」切换显示器以及 App 切到后台返回时，自动恢复对应显示器的缩放和位置。
- **快捷切屏**：将远控工具栏中的「展开所有窗口」「显示桌面」替换为「显示器1」「显示器2」，并高亮当前显示器。没有双显示器需求时可单独关闭。
- **App 内设置**：从 UU「我的 → 设置 → uu 远控增强」进入，使用总开关和各功能开关选择需要的增强；首次使用全部关闭，关闭总开关会保留子设置。

## 使用

安装后彻底退出并重新打开 UU，在「我的 → 设置 → uu 远控增强」打开总开关，再选择需要的功能。仅开启总开关不会自动打开其它功能。

合并版包含原「UU远控切屏」的功能，以后只维护 uuhelper。安装包已声明与旧切屏包互斥，包管理器安装时会要求替换旧切屏插件；普通更新不会清除已保存的开关选择。

已安装测试包的用户，请在包管理器中手动选择正式版 1.0.2 覆盖安装。
